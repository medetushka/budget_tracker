# Мои деньги — трекер расходов для Android

Простое приложение: вписываешь траты за день, оно их запоминает и показывает, куда уходят деньги.
Работает без интернета, все данные хранятся только на телефоне.

## Что умеет

- **Сегодня** — быстро добавить трату: сумма, категория, комментарий. Можно листать дни или выбрать дату в календаре и дописать трату задним числом.
- **Лимит на день** — фиксированная сумма в настройках: на главном экране видно, сколько ещё можно потратить сегодня, превышение подсвечивается красным; в истории такие дни помечены ⚠, в статистике — счётчик дней в лимите / сверх лимита и линия лимита на графике.
- **Бюджет на месяц** — прогресс за месяц; если лимит на день не задан, приложение само считает его из остатка бюджета.
- **История** — все траты по месяцам, сгруппированы по дням, с поиском и фильтром по категории.
- **Статистика** — итог за месяц, средний расход в день, сравнение с прошлым месяцем, график по дням, доли категорий, самые крупные траты, график за 12 месяцев.
- **Редактирование** — нажми на трату, чтобы изменить или удалить её (удаление можно отменить).
- **Категории** — свои категории с эмодзи, переименование, сортировка.
- **Экспорт в CSV** (открывается в Excel / Google Таблицах), **резервная копия** и **восстановление** из файла.
- Светлая и тёмная тема, цвета Material You на Android 12+.

Android 8.0 и новее.

## Установка на телефон

1. Открой страницу **Releases** репозитория на GitHub.
2. Скачай файл `MoneyTracker-x.y.z.apk` из последнего релиза.
3. Открой его на телефоне и разреши установку из этого источника, если Android спросит.

Новые версии ставятся поверх старой, данные сохраняются (пока релизы подписаны одним и тем же ключом — см. ниже).

## Как выпустить релиз

Релизы собирает GitHub Actions (`.github/workflows/release.yml`), когда в репозиторий пушится тег `v*`:

```bash
git tag v1.0.0
git push origin v1.0.0
```

Через 3–5 минут в разделе Releases появится APK. Номер версии берётся из тега (`v1.2.3` → versionName `1.2.3`, versionCode `10203`), поэтому каждый следующий тег должен быть больше предыдущего.

### Подпись релизов (один раз)

Android устанавливает обновление только если оно подписано тем же ключом. Ключ лежит **вне репозитория**:
`C:\Users\medet\.money-keys\release.jks`, пароли — в `keystore.properties` (в `.gitignore`).
**Сохрани копию этого ключа** — без него обновления не встанут поверх установленного приложения.

GitHub нужны 4 секрета репозитория (Settings → Secrets and variables → Actions):

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | файл `release.jks` в base64 |
| `SIGNING_STORE_PASSWORD` | `storePassword` из `keystore.properties` |
| `SIGNING_KEY_ALIAS` | `keyAlias` из `keystore.properties` |
| `SIGNING_KEY_PASSWORD` | `keyPassword` из `keystore.properties` |

Быстрее всего через GitHub CLI (Git Bash, из папки проекта, после создания репозитория на GitHub):

```bash
base64 -w0 /c/Users/medet/.money-keys/release.jks | gh secret set KEYSTORE_BASE64
grep storePassword keystore.properties | cut -d= -f2- | tr -d '\r\n' | gh secret set SIGNING_STORE_PASSWORD
grep keyAlias keystore.properties | cut -d= -f2- | tr -d '\r\n' | gh secret set SIGNING_KEY_ALIAS
grep keyPassword keystore.properties | cut -d= -f2- | tr -d '\r\n' | gh secret set SIGNING_KEY_PASSWORD
```

## Локальная сборка

Нужны JDK 17+ и Android SDK (путь в `local.properties`).

```bash
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`. Если есть `keystore.properties`, сборка подписывается релизным ключом, иначе — отладочным.

## Устройство проекта

- Kotlin + Jetpack Compose (Material 3), одна Activity.
- `data/Repository.kt` — все данные в памяти + JSON-файл `money.json` во внутреннем хранилище приложения, атомарная запись после каждого изменения.
- `data/Format.kt` — форматирование сумм и дат, разбор ввода (`1500`, `1 500,50`, `500+300`).
- `ui/screens/` — экраны «Сегодня», «История», «Статистика», «Настройки».
- Суммы хранятся в копейках/тиынах (`Long`), без ошибок округления.
